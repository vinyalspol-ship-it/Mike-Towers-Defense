# Zombies Must Come Down: TWD

Tower defense 2D de zombis (Phaser 4 + Vite). 20 niveles, 11 defensas con 3 caminos de mejora, árbol de mejoras permanente, equipo, códice y estrellas por nivel.

## Jugar
- **En línea:** el enlace de GitHub Pages del repositorio (funciona en móvil y ordenador).
- **En tu ordenador:** `npm install` y `npm run dev` (o doble clic en `Jugar.bat`).
- **Versión para publicar:** `npm run build` crea la carpeta `dist`.

La partida se guarda en el navegador de cada jugador (localStorage).
Herramientas de prueba (saltar nivel, +100 de oro, +2 cerebros): solo con `npm run dev` o añadiendo `?dev` a la dirección.

## Controles
Arrastra una defensa al mapa (o 1-9 y clic), toca una defensa para mejorarla, Espacio = siguiente oleada, F = velocidad, M = música.
